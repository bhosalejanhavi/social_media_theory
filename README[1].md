# Social Media Theory

A free, beginner-friendly digital marketing knowledge website.

## Files
- index.html — main website
- style.css — design and responsive layout
- script.js — navigation and mini-lesson interactions

## Instagram link
The Instagram buttons currently point to `https://www.instagram.com/`.
Replace that URL in `index.html` with your own Instagram profile URL.

## Free hosting
This is a static website and can be hosted free on GitHub Pages, Netlify, or Vercel.
